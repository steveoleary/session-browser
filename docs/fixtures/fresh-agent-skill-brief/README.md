# Fresh-agent skill brief

A frozen corpus and four research questions, used two ways.

`verify_case.py` is the deterministic half: it runs the commands the skill
teaches against `home/` and asserts they still reach the documented answers —
*and* that the traps those commands exist to escape are still traps. Run it
with the other fixtures:

```bash
python -m session_browser.case_runner run
```

or on its own:

```bash
.venv/bin/python docs/fixtures/fresh-agent-skill-brief/verify_case.py candidate
```

`brief.md` is the qualitative half: the same four questions, written to be
handed to an agent that has never seen this repository, plus the friction
report to read afterwards. It is not scored and not automated, because the
consumer is a model and this repository does not gate on stochastic checks.

## Why it exists

Two ad-hoc runs of exactly this shape on 2026-08-14 found more real defects
than any other check in the repository: a `--repo` wording error that produced
a count inflated by 35.8%, a `stats`/`list` disagreement, unstated `--limit`
omission behaviour, `transcript_health` documented only where no agent could
reach it, and `--repo`'s help naming the wrong provider as the risky one. Two
of those were in text written that same day. Nothing else here catches the
class, because it is documentation failing against its only real consumer.

## The corpus

Eight Claude sessions in three projects, generated by `build_home.py` and
committed so the answers cannot move. Each project carries one trap:

| trap | where | the wrong answer it produces |
| --- | --- | --- |
| `--repo`/`--cwd` are substrings | `coffee_run` and `coffee_run_private` | `--repo coffee_run` returns 6 sessions; 3 are the other project |
| `stats` never opens a transcript | an empty file in `coffee_run` | `stats` totals 8; only 7 can be read |
| a hit is as often a quotation | `tea_break` | 5 hits on one phrase; 4 are text the agent read |
| sessions self-correct | `tea_break` | the confident middle names a machine the ending retracts |

Regenerate the tree with:

```bash
.venv/bin/python docs/fixtures/fresh-agent-skill-brief/build_home.py
```

It rewrites `home/` from scratch and is deterministic, so a rebuild that
changes any committed file means a provider layout changed, not that the
corpus drifted.

## When to run it

On changes to what drifts: `skills/using-session-browser/SKILL.md`, the
argparse help in `session_browser/cli.py`, and the module docstrings the skill
points at. Not on every commit — the deterministic half is cheap enough to run
with the other fixtures, but the live half costs an agent session.
